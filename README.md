# 中秋 · 粒子动画

一个自包含的单页粒子动画。直接用浏览器打开 `index.html` 即可，无需服务器、无需联网。

## 玩法

- **双击画面**：爱心炸开，重聚成「中秋」那幅画（月亮 / 楼阁 / 兔子 / 灯笼 / 祥云 / 远山 / 桂花 + 行楷「中秋节快乐」）
- **再双击**：炸回爱心
- **按住拖动**：转动爱心，可看侧面（中秋那一幕是平面画，不响应拖动）
- 手机竖屏 / 横屏 / 桌面浏览器都能开，会自动按屏幕大小调整粒子数

## 说明

- 全部画面由代码程序化生成（矢量剪影 + 隐式方程拒绝采样），**不含任何第三方图片素材**。
- 静态数据（粒子位置、颜色、掩膜）在 Python 里预先烘焙进 HTML，浏览器端只做每帧渲染。
- 桌面版（含 MP4 导出）源码在本地工程 `heart_animation`，未随本仓库发布。
